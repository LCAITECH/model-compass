## `deepseek#direct-api`

The API is billed and managed through the DeepSeek Platform, separate
from any other DeepSeek product.

1. Create/use a DeepSeek Platform account.
2. Add billing under the Platform's account settings.
3. Generate an API key: [API keys](https://platform.deepseek.com/api_keys).
4. Follow the official docs for your first call: [DeepSeek API docs](https://api-docs.deepseek.com/).

Source: [DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing), consulted 2026-08-13.
